# 🤖 AI & Computer Science Micro-Projects

Welcome to my consolidated repository of 13 Artificial Intelligence and computer science micro-projects. This repository contains various implementations of search algorithms, constraint satisfaction problems, probabilistic reasoning, and knowledge graphs.

> **📝 Note:** Each individual project folder below contains its own dedicated `README.md` file with specific setup instructions, execution details, and technical documentation.

---

## 📂 Project Directory

### Search Algorithms & Pathfinding
* [**Adversarial Search Suite**](./adversarial-search-suite) — Python implementations of Minimax, Alpha-Beta Pruning, and MCTS applied to discrete game environments.
* [**Dynamic Obstacle UGV**](./Dynamic-Obstacle-UGV-) — A* search pathfinding simulation for an Unmanned Ground Vehicle navigating real-time dynamic obstacles.
* [**Static Obstacle UGV**](./Static-Obstacle-UGV-) — A* search pathfinding simulation across varying static obstacle densities.
* [**India Road UCS**](./India-Road-UCS) — Priority-queue-based Uniform Cost Search (UCS) exploring cost-effective routes across an Indian cities dataset.
* [**Uninformed Search Evaluator**](./Uninformed-Search-Evaluator) — Benchmarking node expansion and execution time for BFS and DFS variants using the Eight Queens puzzle.

### Constraint Satisfaction Problems (CSP)
* [**Australia Map Coloring CSP**](./australia-map-coloring-csp) — A zero-dependency solver for the classic Map Coloring CSP applied to Australia's territories.
* [**Telangana Map Coloring CSP**](./Telangana-Map-Coloring-CSP) — Backtracking algorithm solving the map coloring problem for the 33 districts of Telangana.
* [**CSP Sudoku Solver**](./CSP-Sudoku-Solver) — An efficient Sudoku solver utilizing constraint propagation and backtracking search.
* [**Cryptarithmetic Solver**](./Cryptarithmetic-Solver) — A brute-force permutation and CSP script to solve the classic "TWO + TWO = FOUR" puzzle.

### Knowledge Representation & Reasoning
* [**AI Knowledge Graph Explorer**](./ai-knowledge-graph-explorer) — An educational exploration using NetworkX to construct and visualize semantic networks.
* [**OntoTravel AI Planner**](./OntoTravel-AI-Planner) — An AI-driven travel agent that queries domain-specific knowledge bases to generate budget-aware itineraries.
* [**Bayesian Network Inference AI**](./bayesian-network-inference-ai) — Exploration of probabilistic modeling and inference using the classic Alarm problem (implemented with `pgmpy`).

### Web Security & Applications
* [**The Confessional Captcha**](./The-Confessional-Captcha) — A Flask-based system implementing session-based CAPTCHA validation and custom input handling.
